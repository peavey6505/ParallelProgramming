Program examples for a course on parallel programming in .NET using C#.
It focuses on practical multithreading with the Task Parallel Library (TPL), PLINQ, and async/await.

**Topics Covered**

- Task Programming (creating, running, cancelling, waiting, and handling exceptions)
- Data Sharing and Synchronization for safe concurrent access
- Concurrent Collections (e.g., ConcurrentBag)
- Task Coordination (continuations and synchronization primitives)
- Parallel Loops for data partitioning and multithreaded iteration
- Parallel LINQ (PLINQ)
- Async/Await and asynchronous programming in .NET
